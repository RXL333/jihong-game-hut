# 鸡泓的游戏小屋

一个手机优先的治愈系小游戏集合网站。领养橘色狸花猫或焦糖棕腊肠狗，为它起名，通过小游戏领取零食与清水，一起慢慢长大。

在线游玩：[打开鸡泓的游戏小屋](https://rxl333.github.io/jihong-game-hut/)。

## 本地打开

Windows 双击 `启动游戏小屋.cmd`。首次会安装依赖并准备游戏副本，随后打开浏览器。
需要 Node.js 24；关闭启动窗口会结束本地预览。

也可以在项目目录运行：

```sh
npm ci
npm run build
npm run preview
```

## 已实现内容

- 默认进入游戏乐园，未领养时也能游玩并收集奖励，之后领养继续使用。
- 首次访问显示 6 步新手指引，介绍游戏、目标奖励、宠物照顾、背包、图鉴和设置；支持前后切换、跳过，并可从页头或设置重新查看。
- 领养二选一、起名与改名，免登录本地存档，备份导出与导入。
- 饱腹度与饮水值 0—100；0 是不足，100 是充足。随真实时间自然下降。
- 零食、丰盛零食、清水、每日保底供给和每日好感经验上限。
- 好感 Lv.1—16，5 个基础动作与 15 个升级解锁动作，每只宠物共 20 个逐帧动作。
- 游戏入口、任务目标、真实游戏成绩回传、待领奖列表、去重与首次成就纪念贴纸。
- 瀑布流游戏卡片，全站采用现成 LiquidGlassJS 毛玻璃材质。
- 轻音乐开关、音量、轻柔动态、动作图鉴和成长手账。

## GitHub Pages 发布

1. 将整个项目放进你准备好的 GitHub 仓库，推送到 `main`。
2. 在仓库 Settings → Pages 中，Source 选择 GitHub Actions。
3. 项目自带 `.github/workflows/deploy.yml`，会自动测试、构建并发布 `dist/`。

站点和三款游戏均使用相对资源地址，适配仓库子路径。
没有服务器、账号、数据库或付费服务依赖。正式 GitHub Pages 站点与本地预览属于不同来源，本地测试存档不会自动成为正式站点的存档；可以使用设置内的导出、导入转移。

`dist/` 是可发布静态目录。也可以将其中内容部署到其他静态托管服务。

## 游戏副本和更新

三款游戏的源码版本固定于 `integrations/games.lock.json`。
`npm run games:sync` 会准备独立集成副本；`npm run build` 仅在固定版本或适配代码变化时重建游戏。
源码缓存位于忽略目录 `.cache/game-sources/`，原小游戏仓库不受修改。
构建后的静态副本位于 `public/games/`，方便离线保留和直接发布。

需要更新游戏时，先把锁文件里的 revision 改为目标提交，再执行 `npm run games:sync`，并验证新增目标仍对应真实游戏事件。
接入新游戏请看 `docs/接入新游戏.md`。
